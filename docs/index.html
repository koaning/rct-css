How theming works
Six variables

Every component reads six CSS custom properties. A built-in theme like slate or olive just sets them. Because the compiled rct.css only ever reads these variables, you can invent a brand-new theme in plain CSS — no Sass, no build step:

.rct-window--sunset {
  --body:  #c8582f;  /* frames/buttons */
  --light: #e8935c;  /* bevel highlight */
  --dark:  #6e2a12;  /* bevel shadow */
  --field: #b34a25;  /* input wells */
  --title: #5a2110;  /* title + hover */
  --page:  #c8582f;  /* tab page */
}

Add class="rct-window rct-window--sunset" to any window and it inherits the whole look. That’s the entire theming system.

Get started

<link rel="stylesheet" href="dist/rct.css">
<script src="js/rct.js" defer></script>  <!-- optional: dropdown niceties -->

<details class="rct-window rct-window--taupe" open>
  <summary class="rct-titlebar">
    <span class="rct-close">X</span>Options
  </summary>
  <div class="rct-body">
    <button class="rct-button">Click me</button>
  </div>
</details>

Make a theme without a build

Every component reads six CSS custom properties. Override them on any .rct-window in plain CSS — no Sass required:

.rct-window--candy {
  --body:  #b0568a;   /* frames, buttons, tabs */
  --light: #dd8cbb;   /* raised bevel highlight */
  --dark:  #5e2748;   /* raised bevel shadow */
  --field: #9c4879;   /* sunken input wells */
  --title: #4a1f38;   /* title bar + menu hover */
  --page:  #b0568a;   /* tab page fill */
}
